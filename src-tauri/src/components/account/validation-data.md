# Datos de validación

Fuente: https://data.iana.org/time-zones/tzdata-latest.tar.gz

Versión tzdb: 2026f. SHA-256 del archivo: 01b4a91cec5167ed48c11e8ab78f2048cead78ce94b0cafcad0ae8c5a3044d3d.

Los nombres de time_zones.txt son Zone y Link de los archivos regionales, etcetera, backward y factory. countries.txt contiene los 249 códigos ISO alfa-2 de iso3166.tab. Solo se usan para pertenencia; no se calculan fechas ni offsets. Datos de IANA de dominio público. Actualizar ambas listas juntas desde una versión revisada si IANA añade zonas o cambia códigos. La API vuelve a validar antes de aceptar.
